DERMLENS (https://dermlens-brown.vercel.app/)
This is a [Next.js](https://nextjs.org) project
This is a skin treatment platform built for project purposes backed by Google Gemini
It analyses your skinproblems and rate them,also analyses your Diet and gives root problems causing to it and helps in builing a balanced diet
Gives complete skincare routine for the same
It even has a Chatbot where you can ask anything related to it 
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
